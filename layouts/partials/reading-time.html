{{- /* 閱讀時間（分鐘，無條件進位，至少 1）= 字數 ÷ 這個語言的閱讀速度（hugo.toml 的 readingSpeed）。 不用 Hugo 內建的 .ReadingTime：它的速度寫死（英文每分鐘 213 字、中文 500 字），中文快得不合理。 字數沿用 .WordCount：中文一個字算一個，英文一個單字算一個（hasCJKLanguage）。 */ -}} {{- $speed := site.Params.readingSpeed | default 200 }} {{- $minutes := math.Max 1 (math.Ceil (div (float .WordCount) $speed)) }} {{- return int $minutes }}
